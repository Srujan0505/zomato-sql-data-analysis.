# Zomato SQL Data Analysis

## 📌 Project Overview

This project analyzes Zomato restaurant data using MySQL to identify useful insights related to restaurants, cuisines, locations, ratings, and pricing.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## 🎯 Objectives

- Analyze restaurant data using SQL
- Identify highly rated restaurants
- Analyze restaurant locations and cuisines
- Explore pricing patterns
- Extract meaningful business insights

## 🔍 SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOIN
- Subqueries
- CASE statements
- Filtering and Sorting

## 📊 Analysis Performed

The project includes SQL queries to analyze:

- Restaurant ratings
- Popular cuisines
- Restaurant locations
- Average pricing
- Restaurant distribution
- Customer-related patterns

## 📁 Project Files

- `zomato_analysis.sql` — Contains the complete SQL queries used for the analysis.
- `README.md` — Project documentation.

## 🚀 How to Run

1. Open MySQL Workbench.
2. Create/open a MySQL connection.
3. Open `zomato_analysis.sql`.
4. Execute the queries step by step.
5. View the results in MySQL Workbench.
